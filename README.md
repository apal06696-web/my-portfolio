# Portfolio — Static Template

This is a minimal, modern portfolio template generated for `[Your Name]`, `[Your Profession]`.

Files created:

- `index.html` — main page with sections: Home, Projects, About, Skills, Contact.
- `styles.css` — styling, responsive layout, color palette and animations.
- `script.js` — small interactions (nav toggle, contact form simulation, year).
- `assets/*.svg` — placeholder vector images for profile and projects.

How to run

1. Open `D:/Demo/portfolio/index.html` in your browser (double-click or use the command below).

   PowerShell:

   ```powershell
   Start-Process D:\Demo\portfolio\index.html
   ```

Customization

- Replace `[Your Name]` and `[Your Profession]` in `index.html` with your details.
- Replace `assets/profile.svg` and `assets/project*.svg` with your photos/screenshots.
- To wire the contact form to a backend, replace the simulated code in `script.js` with a fetch() call to your API endpoint.

Color palette and typography

- Primary accent: cyan `#06b6d4`.
- Background: deep navy gradient.
- Font: Inter (from Google Fonts). Replace with your preferred font if desired.
